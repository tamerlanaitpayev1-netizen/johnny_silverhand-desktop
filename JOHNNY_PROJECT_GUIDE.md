# Johnny Silverhand Desktop Engram (C# .NET WPF + Python)

Полноценный десктоп-компаньон **Джонни Сильверхенда** в духе [capri-desktop](https://github.com/lachydotmcg/capri-desktop), спроектированный и настроенный под ноутбук **AMD Ryzen 7 250, 16 ГБ DDR5, NVIDIA GeForce RTX 5060 Laptop 8 ГБ VRAM, Windows 11**.

## Что уже реализовано (Этапы 1–7)

| Этап | Статус | Реализация в проекте |
| :--- | :--- | :--- |
| **Этап 1. Окружение** | ✅ Готово | Python 3.12 (`backend/venv`), .NET SDK (`RollForward=LatestMajor`), FFmpeg и Ollama |
| **Этап 2. Мозг и характер** | ✅ Готово | [engram_server.py](backend/engram_server.py), [personality.md](backend/personality.md), [me.md](backend/me.md) на `127.0.0.1:8077` |
| **Этап 3. Оверлей и физика окон** | ✅ Готово | Прозрачный киберпанк-оверлей [MainWindow.xaml](frontend/MainWindow.xaml) + привязка к окнам через `user32.dll` в [MainWindow.xaml.cs](frontend/MainWindow.xaml.cs) |
| **Этап 4. Русский голос + DSP + RVC** | ✅ Готово | Русский синтез `edge-tts` + фильтр биочипа `apply_relic_engram_dsp` + автоподхват RVC v2 моделей Ильи Бледного из `backend/models/johnny_ru/` |
| **Этап 5. Спрайты и анимации** | ✅ Готово | 5 состояний в `assets/sprites/` (`johnny_idle.png`, `johnny_talk.png`, `johnny_drag.png`, `johnny_guitar.png`, `johnny_glitch.png`) |
| **Этап 6. Зрение и управление ПК** | ✅ Готово | Скриншоты через `mss` для Vision-моделей (`qwen2.5vl:7b`), таймер реакций раз в 12 минут, управление громкостью, медиа, вкладками и приложениями |
| **Этап 7. Трей и лаунчер `.exe`** | ✅ Готово | Иконка в системном трее (`relic_tray.ico`), глобальный хоткей `Ctrl + Alt + H`, автозапуск Python из C# и релизная сборка в `release/JohnnyOverlay.exe` |

## Быстрый запуск в один клик

Запусти файл **[Start-Johnny.bat](Start-Johnny.bat)** или напрямую **[release/JohnnyOverlay.exe](release/JohnnyOverlay.exe)**.
Клиент C# автоматически поднимет фоновый Python-сервер `backend/engram_server.py` (без лишних окон консоли) и выведет Джонни поверх окон Windows.

## Управление персонажем

* **Двойной клик левой кнопкой мыши по Джонни** — открыть/скрыть строку чата (`Enter` — отправить, `Esc` — закрыть).
* **Перетаскивание мышкой** — переместить Джонни. Если зажать **Shift** при перетаскивании, автопривязка к активным окнам отключится, и Джонни останется сидеть там, где ты его оставил.
* **Правый клик по Джонни (или клик по иконке Relic в системном трее)**:
  * `👁 Прокомментировать мой экран (Vision)` — делает скриншот и отправляет его Джонни.
  * `🎸 Сыграть рифф Samurai (Гитара)` — включает состояние игры на электрогитаре.
  * `📌 Привязка к активным окнам` — включает/выключает посадку на рамку активного окна.
  * `💊 Псевдоэндотризин (Управление ПК)` — разрешает или запрещает Джонни выполнять команды `ACTION:` на ПК.
  * `⏱ Фоновые реакции (раз в 12 мин)` — включает/выключает внезапные комментарии Джонни о твоём текущем окне.
  * `📝 Редактировать характер (personality.md)` / `🧠 Редактировать память о Ви (me.md)` — открывает файлы настройки личности в Блокноте.
* **Глобальное сочетание клавиш `Ctrl + Alt + H`** — мгновенно скрыть или вернуть Джонни на экран во время игры или работы.

## Подключение RVC-модели голоса Ильи Бледного

Положи файлы весов `.pth` и индекса `.index` голосовой модели русского дубляжа Джонни Сильверхенда в папку:
```text
backend/models/johnny_ru/
```
При наличии установленного пакета `rvc-python` функция `try_apply_rvc_voice_conversion()` в `backend/engram_server.py` автоматически прогонит сгенерированную речь через RVC v2 на твоей RTX 5060 перед наложением DSP-эффекта биочипа Relic.
